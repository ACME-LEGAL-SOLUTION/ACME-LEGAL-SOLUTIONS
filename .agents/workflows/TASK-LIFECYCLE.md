# ACME Task Lifecycle

## 1. Task
State the smallest independently verifiable objective.

## 2. Inspect
Read the current implementation, contracts, tests and relevant authoritative documentation before changing code.

## 3. Plan
Identify affected boundaries, risks, acceptance criteria and rollback path.

## 4. Execute
Make the smallest coherent implementation change. Do not mix unrelated work.

## 5. Validate
Run targeted tests first, then the relevant broader regression suite. Validate operational claims with direct evidence where applicable.

## 6. Review
Check security, authorization, provenance, data integrity, error handling, documentation and unintended side effects.

## 7. Affirm completion
Only mark complete when acceptance criteria are satisfied and evidence is recorded. Otherwise report the exact blocker.

## 8. Stop
Do not silently continue into another major task.

## 9. Next task
State exactly one next independently verifiable task with its acceptance criteria.
