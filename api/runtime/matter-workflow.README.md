# End-to-End Matter Workflow

The workflow coordinates intake-to-closure orchestration without granting AI independent professional authority.

`matter -> conflict_check -> evidence -> routing -> knowledge -> work_package -> human_review -> human_modified -> human_approved -> final_action -> closed`

Approval and finalization require an actor explicitly marked `human: true`. Conflict-positive matters are blocked before specialist execution. The workflow preserves work-package versioning, provenance and audit events.
