# Professional Work Package Engine

The work package is the governed bridge between matter intake/research and professional action. It records issue, facts, assumptions, jurisdiction, applicable date, evidence, authorities, specialist findings, analysis, uncertainty, confidence, recommended actions, required documents, required tasks, provenance and audit history.

Lifecycle: `draft -> review -> modified -> review/approved -> finalized`.

Approval and finalization require an explicit human actor. AI agents may prepare and modify analysis only through governed application workflows; they cannot independently approve or finalize professional work.
