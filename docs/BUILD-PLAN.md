# ACME Build Plan

This is the implementation sequence for the ACME platform. Each production change is committed independently so the build remains auditable and reversible.

## Phase 1 — Public Experience
1. Semantic public-site shell and information architecture
2. Premium visual system and responsive layout
3. World / jurisdiction presentation
4. Capabilities and intelligence experience
5. Motion, accessibility and performance hardening
6. Consultation / ASK ACME entry points

## Phase 2 — Application Foundation
7. Application shell and authenticated routing
8. Identity, roles and authorization boundaries
9. CRM, people, organizations and relationships
10. Matters, parties, tasks and diary
11. Documents, evidence and audit trail

## Phase 3 — Intelligence
12. AI Gateway and provider abstraction
13. Context assembly and scoped tools
14. Provenance, confidence and source chains
15. Human review / modification / approval gates
16. Specialist agents

## Phase 4 — Legal Knowledge
17. Jurisdictions and authorities
18. Legal instruments and historical versions
19. Source verification and knowledge acquisition
20. Research and case-analysis workflows

## Phase 5 — Operations
21. Partner verification and international routing
22. Billing, invoices, payments and accounting
23. Notifications and client communications
24. Client portal
25. Professional portal
26. Director / Master Command Center

## Phase 6 — Production Readiness
27. Security hardening and audit validation
28. Accessibility and performance testing
29. Backup / recovery implementation after infrastructure decisions are finalized
30. GoDaddy public deployment
31. Authenticated production intake and operational services
32. Production acceptance testing

## Non-negotiable rules
- Do not fabricate legal credentials, regulatory status, integrations or operational capability.
- AI assists; required professional decisions remain human-controlled.
- Client operational documents and secrets never belong in source control.
- Production infrastructure choices that the dossier leaves unresolved must remain configurable rather than invented.
- Public website deployment and authenticated operational services remain separate security boundaries.
