# ACME Legal Solutions

Premium international legal, accounting and business counsel platform.

ACME is being delivered as working vertical slices with validation gates. The current line includes the core platform foundation, governed AI execution architecture, persistent matter lifecycle, self-hosted production deployment plane, public site, Ask ACME intake foundation, approved ACME brand asset, and accelerated free-source legal research foundation.

`assets/brand/acme-logo.jpg` is the **sole approved ACME logo**. Do not substitute, redraw, generate, simplify, or introduce another ACME logo or mark anywhere in the public site, application UI, metadata, favicon, social/SEO surfaces, or generated content.

ACME prefers authoritative public/free sources for legal research. Research results carry provenance and verification state and are not presented as AI-generated legal opinions. Indian Kanoon is optional authorized enrichment, never an unlicensed scraping target or mandatory paid dependency.

Requires Node.js >= 20. Run `npm test` for the repository test suite and `npm start` to run the API locally.
