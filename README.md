# ACME Legal Solutions

Premium international legal, accounting and business counsel platform.

## Delivery status

The platform foundation, governed AI execution architecture, persistent matter lifecycle, self-hosted production deployment plane, public site, Ask ACME intake foundation, and approved ACME brand asset are implemented. The legal knowledge layer is being accelerated using free/public authoritative sources, beginning with India Code.

## Brand

`assets/brand/acme-logo.jpg` is the **sole approved ACME logo**. Do not substitute, redraw, generate, simplify, or introduce another ACME logo or mark anywhere in the public site, application UI, metadata, favicon, social/SEO surfaces, or generated content.

## Legal knowledge policy

ACME must prefer authoritative public/free sources for legal research. Source results are returned with provenance and verification state. Public research is source-attributed and is not presented as an AI-generated legal opinion. Indian Kanoon is an optional authorized enrichment source and must never be treated as an unlicensed scraping target or a mandatory paid dependency.

## Development

Requires Node.js >= 20. Run `npm test` for the repository test suite and `npm start` to run the API locally.
